How the solver algorithms work

The population contains solver programs. Executing a program produces a feasible witness: one sign per vertex. The evaluation harness recomputes that witness’s cut and summarizes three trials into strategy fitness.

The signed objective and a real local move

For signs sᵢ ∈ {−1,+1}, maximize C(s) = Σ wᵢⱼ(1 − sᵢsⱼ)/2. A positive crossing earns its weight; a negative crossing incurs its negative weight. An uncut edge contributes zero. Flipping vertex i changes the objective by Δᵢ = sᵢ Σⱼ wᵢⱼsⱼ.

This four-vertex example has edges A—B:+2, B—C:−1, C—D:+2, D—A:+1. Use a flip to check the formula against complete rescoring.

Tabu Search

Question: How do we prevent an exploratory move from being immediately undone?

Maintain current signs, one-flip gains, a tabu expiry for each vertex, and a separate best witness. Choose the highest-gain admissible flip, including a zero or negative gain. A move is admissible when its restriction has expired, or when aspiration predicts a new global best. Seeded random choice breaks gain ties.

Example: flip B at iteration 5 with tenure 3. Reversing B is forbidden at iterations 6, 7 and 8; it is normally available again at 9. If reversing B at iteration 7 would beat the best cut ever seen, aspiration permits it early. Accepting a worsening current state does not overwrite the best witness.

eligible[i] = iteration ≥ expiry[i]
              OR current_cut + gain[i] > best_cut
v = highest_gain(eligible), seeded tie break
flip(v)
expiry[v] = iteration + tenure + 1
if independently_rescored_cut > best_cut: retain a copy

tenure controls short-term memory. restart_after counts stagnating iterations before a random exploratory restart; zero disables it. max_work counts iterations, including waits when no move is admissible. The classroom maximum is 20,000 iterations per stage; tenure and restart_after must lie in 0–1,000. This is the preserved project’s one-flip variant with aspiration and worsening moves.

Simulated Annealing

Question: When should a search accept a loss?

Propose a uniformly random vertex flip. Improving moves are accepted. A loss Δ<0 is accepted with probability exp(Δ/T), where temperature T decreases geometrically over the proposal budget. A final bounded improving-flip polish is optional. Retain the best witness even while the current trajectory worsens.

Example: a move loses two cut units (Δ=−2). Change the temperature below. This calculates an acceptance probability; it is not a model inference or measured demo trajectory.

At T=2 the probability is about 36.8%; at T=0.5 it is about 1.8%. Cooling trades early exploration for later selective improvement. One sweep means n proposals, not n accepted flips.

for k in 0 .. max_work−1:
    T = geometric_schedule(T_initial, T_final, k)
    choose vertex v uniformly
    accept if gain[v] ≥ 0 or log(U) < gain[v] / T
    retain independently verified improvements
optional bounded improving-flip polish

The classroom maximum is 200,000 proposals per stage. Temperatures must be positive and finite; polish is a boolean. Actual time and the enclosing program’s shared trial budget also bound execution.

Breakout Local Search

Question: What happens after improving flips can no longer escape the same basin?

Alternate steepest improving descent with perturbation. When the local optimum repeats, increase the jump magnitude; otherwise restore its base value. Track stagnation and choose between directed tabu perturbations and random perturbations. Directed choices may use a single vertex or a pair.

Example: descent reaches local optimum L. A one-flip perturbation followed by descent returns to L. The next jump grows, allowing several perturbing flips before descent resumes. Those flips can worsen the current cut. If a different local optimum is reached, the jump returns to its base size. The best witness remains protected throughout.

descent until no positive-gain flip remains
if this local optimum repeats: jump += 1
else: jump = configured_base_jump
choose directed or random perturbation from stagnation feedback
perform bounded perturbing flips, then descend again

jump sets the base perturbation size. stagnation controls the adaptive response. p_min floors the directed-mode probability; q chooses directed single versus pair moves; tenure_min/max bound its tabu memory. The cap is 12,000 individual flips, covering descent and perturbation. This work unit differs from a Tabu Search iteration or an annealing proposal.

Actual Luna example: the first-round Burer–Monteiro → Breakout Local Search program used 9,000 flips and completed three reference matches. The second round increased that to 10,300; one trial exceeded the time limit. Its witness remained valid but the strategy was excluded from complete-trial ranking.

The rank-two Burer–Monteiro method

Question: Can continuous geometry help search a discrete partition?

Replace a sign by a two-dimensional unit vector vᵢ=(cos θᵢ,sin θᵢ). Optimize the relaxed objective Σ wᵢⱼ(1−vᵢ·vⱼ)/2 by coordinate updates. Project the vectors along candidate directions to obtain signs, then improve the discrete cut with a local polish. The method is nonconvex; its encountered relaxed value is not a certified upper bound.

Example: vectors at angles 20° and 160° have opposite projections on the horizontal axis, so that rounding direction separates them. Angles 20° and 40° project to the same sign. Try multiple directions because the partition depends on the projection.

coordinate sweeps over rank-two unit vectors
for each allowed projection direction r:
    s[i] = sign(dot(v[i], r))
    polish and recompute the original signed cut
retain the best rounded witness and any better warm start

The classroom cap is one solve with at most 60 coordinate sweeps and 16 rounding directions. The initial population uses 20 sweeps and 8 directions. In new runs, a retained Burer–Monteiro stage after stage one lifts the incoming partition to angles 0 or π, adds seeded uniform angular offsets in [−0.35, 0.35] radians, then optimizes, rounds and polishes. The better incoming or returned partition survives. A first or fresh Burer–Monteiro stage keeps the original independent vector search. Source identifier: bm.

Composing and evolving strategy programs

Question: How is an algorithmic proposal different from a guessed assignment?

A program is one to three stages. Each stage selects an implemented kernel, its parameters, a work cap and a start rule. For example:

Burer–Monteiro: 20 sweeps, 8 directions, retained start
→ Breakout Local Search: 9,000 flips, retained start

fresh=false passes a copy of the best witness retained within that trial. fresh=true gives that stage a seeded random exploratory start; a worse result cannot erase the old best. The dense case shares eight numerical seconds across the entire program. Remaining time is allocated across remaining stages, and unused time carries forward.

Replacement versus composition: replacing a Burer–Monteiro parent with a one-stage Tabu Search child evaluates that new solver from the common raw starts. A Burer–Monteiro → Tabu Search child passes its retained partition to Tabu Search. A retained Tabu Search → Burer–Monteiro child now embeds and perturbs that partition before vector refinement. Both orders share the same total trial allowance. Earlier recorded replays preserve the previous behavior and do not demonstrate this new downstream refinement.

The four initial solver programs and all children use identical raw seeded starts for three trials. Rank complete programs by median cut, minimum cut, fewer stages and stable normalized genome identity; retain the top three. Luna sees those selected programs, trial evidence, prior failures, duplicates, bounds and remaining budget. It does not receive solution vectors, the numerical preset or the replay.
