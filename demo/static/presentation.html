Frames and overlay slides

A frame holds one teaching idea. Each advance reveals one block, producing the next overlay slide within that same frame.

Right arrow, Space or Page Down: next reveal. Left arrow or Page Up: previous reveal. D: demo / return. F: full screen. Home / End: first / last frame in the current section. Use Appendix to open the optional implementation frames; Main presentation returns to your previous main frame.

Ask the visible question, wait about five seconds, then reveal the mechanism and answer. The main plan is 21 minutes 40 seconds plus 45 seconds reserve. The optional architecture/API appendix adds 2 minutes 35 seconds.

Saving a prose file automatically rebuilds the frames and updates this tab, preserving your frame and reveal. Invalid drafts keep the last successful frames and show an error. PDFs are updated with just build.

Rehearse aloud starts a local clock. Save timing downloads your actual frame and demo timings; it makes no API calls. The clock does not certify that you spoke aloud.
